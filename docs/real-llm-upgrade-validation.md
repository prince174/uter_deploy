# Реальная LLM, резервная копия и обновление

[Изолированный CI, run 40639754098](https://github.com/prince174/uter_deploy/actions/runs/40639754098) успешно проверил Compose и Kubernetes с настоящей моделью Qwen 2.5 0.5B в Ollama. Каждый backend использовал свой временный GitHub-hosted runner, без исходников Uter.

Проверка скачивает установочные архивы двух релизов, проверяет SHA256 и digest модели, устанавливает первую версию через `install.py`, затем принимает её под управление `uterctl`. Она отправляет запрос через Uter к модели, записывает контрольное значение в Redis и проверяет цепочку аудита. При обновлении контроллер останавливает пишущие компоненты и создаёт зашифрованную копию runtime, Redis и аудита; Kubernetes также сохраняет сведения о ресурсах. Копия проверяется до обновления. После обновления CI снова проверяет ответ модели, состояние Redis, цепочку аудита и образы запущенных компонентов. Redis-снимок экспортируется, проверяется и загружается в отдельный временный Redis, где проверяется контрольное значение.

## Ограничения

- CI создаёт **тестовые** подписывающий ключ, комплекты и значения версий. Выпущенных подписанных комплектов и подтверждённой совместимости пользовательских данных пока нет; нельзя использовать тестовые ключи для реального обновления.
- [Позднейший прогон](https://github.com/prince174/uter_deploy/actions/runs/40648769218) восстановил Uter в новые Compose-проект и Kubernetes-namespace с проверкой LLM, Redis и аудита. Старые ресурсы не перезаписываются; переключение трафика и внешние хранилища остаются за оператором. `scripts/restore_backup.py` отдельно только экспортирует данные, включая секреты, в приватный каталог.
- При создании копии доступность сервиса временно прерывается. Храните ключ и копию отдельно, вне каталога установки и вне одного устройства хранения; без ключа копия непригодна. Внешние LLM и внешние хранилища не входят в копию.
- Модель небольшая и работает на CPU; другие модели, провайдеры, TLS, RAG, HA, нагрузка и пользовательские политики требуют отдельных проверок. Kind не доказывает работу сетевых ограничений NetworkPolicy.

## Повторить CI

В Actions запустите `Test installation adoption and encrypted backup`. Runner скачает образ Ollama, модель около 400 МБ, образы Uter и зависимости. Отчёты доступны в артефактах `adopt-backup-compose-evidence` и `adopt-backup-kubernetes-evidence`. Прогон рассчитан только на одноразовый GitHub-hosted runner, не на существующий стенд.
